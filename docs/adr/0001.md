### ADR-0001: Python + FastAPI + SQLite as the core stack

- **Status:** Accepted
- **Context:** 3-hour budget; the team is vibecoding with an AI IDE; needs a strong LLM and data ecosystem, auto-generated API docs and zero infra setup.
- **Decision:** Python 3.12, FastAPI, SQLModel (Pydantic + SQLAlchemy), SQLite file DB.
- **Alternatives considered:** Node/NestJS (more boilerplate); Django (heavier, slower to scaffold); Postgres (infra overhead for no demo benefit).
- **Consequences:** + fastest scaffolding, OpenAPI docs for free, Pydantic reused for LLM output validation. − SQLite is not for production concurrency. Mitigation: the repository layer lets us swap to Postgres later.
