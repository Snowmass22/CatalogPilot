### ADR-0002: Hexagonal (Ports and Adapters) architecture

- **Status:** Accepted
- **Context:** Quality-of-code scoring; we must also guarantee a demo even if WooCommerce or the LLM fails.
- **Decision:** Define `StorePort` and `LLMPort` interfaces. Provide real and mock/fixture adapters. Domain and services depend only on ports.
- **Consequences:** + testable without network, + demo fallback, + clean story for judges. − slightly more files up front (worth it).
