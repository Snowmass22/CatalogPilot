### ADR-0003: WooCommerce REST API v3 with the batch endpoint, SKU as the idempotency key

- **Status:** Accepted
- **Context:** Sync must be re-runnable without creating duplicates; WooCommerce limits per-request volume.
- **Decision:** Authenticate with consumer key and secret (HTTPS or Basic). Use `POST /wp-json/wc/v3/products/batch` (create, update arrays, ≤100 each). Look up existing products by SKU (`GET /products?sku=`) and persist `woo_id` on first sync. Map attributes to global attributes (`/products/attributes`) and terms.
- **Alternatives:** WP-CLI (needs server access); direct DB writes (fragile, unsafe); CSV importer plugin (not programmable).
- **Consequences:** + idempotent, + efficient. − WooCommerce rate or timeouts: handled with retries, exponential backoff and per-item result parsing (batch returns per-item errors).
