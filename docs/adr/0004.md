### ADR-0004: Agents propose, deterministic code disposes (Human-in-the-loop)

- **Status:** Accepted
- **Context:** LLMs hallucinate; a wrong price or SKU pushed to a live store is costly.
- **Decision:** Agents return **structured JSON validated by Pydantic**; outputs are stored as *suggestions*. Writes to the PIM catalog happen only on user confirmation; writes to WooCommerce happen only through an approved SyncPlan. Numeric and identifier fields (price, SKU, stock) are never LLM-generated from scratch. They are only transformed by validated rules (e.g. "+10%").
- **Consequences:** + safe and explainable (strong "agentic AI" narrative), + testable with fixtures. − one extra click for the user, which we position as a feature.
