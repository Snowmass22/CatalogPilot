### ADR-0005: LLM provider abstraction with Gemini as the default

- **Status:** Accepted
- **Context:** Antigravity ships in the Google/Gemini ecosystem; we need structured output and tool calling; the demo must survive API failures.
- **Decision:** `LLMPort.generate(prompt, schema) -> BaseModel`. Default adapter: Gemini via `google-genai` with JSON schema output. `FixtureLLMAdapter` replays cached responses keyed by hash of the input (record mode while building, replay mode in demo or CI).
- **Consequences:** + provider swap is trivial, + deterministic tests, + offline demo. − fixtures must be recorded before the demo (add to the checklist).
