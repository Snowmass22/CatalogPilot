### ADR-0007: Rule-based plus LLM-assisted Health Score

- **Status:** Accepted
- **Context:** Score must be explainable and stable; LLM-only scoring is non-deterministic.
- **Decision:** Deterministic weighted rules produce the numeric score (name length, description length, image present, required attributes per category, price greater than 0, SKU format, duplicate check). The Quality Agent only produces *natural-language explanations and fix suggestions* from the rule results.
- **Suggested weights:** required attributes 30, description 20, images 20, pricing sanity 15, naming 10, duplicates 5.
- **Consequences:** + reproducible numbers, + unit-testable. − LLM adds nuance only to the explanation, which is the intended scope.
