### ADR-0008: Server-rendered UI (Jinja2 + HTMX + Tailwind CDN)

- **Status:** Accepted
- **Context:** No time for a separate SPA build, state management and CORS. We still need a polished, interactive demo.
- **Decision:** Server-rendered pages with HTMX partial updates and Tailwind via CDN. One screen per pillar: Dashboard, Catalog, Import, Sync.
- **Consequences:** + one codebase and one deploy, + fast to vibecode. − less rich client interactivity, which is acceptable
