### ADR-0009: WooCommerce environment and fallback strategy

- **Status:** Accepted
- **Context:** A live WooCommerce instance may be hard to provision under time pressure.
- **Decision:** Primary: Docker Compose (WordPress + MySQL + WooCommerce, with `wp-cli` bootstrap script). Alternatives: a free WordPress test site or LocalWP. Fallback: `MockStoreAdapter` implementing the same API contract, selected by `STORE_MODE=mock|live`.
- **Consequences:** + demo never blocked. Action: **start the WooCommerce container in the first 10 minutes** (it is the longest-lead item).
